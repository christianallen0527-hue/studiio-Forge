# Wanted vs Not Okay

Living list from studio feedback. Update this whenever the human corrects the AI.

## WANTED

- **Music:** the original High Place Mortgage bed from the first loved ad (`high_place_mortgage_sponsor_stock.mp4` audio / that same upbeat clean track). Seamless at all times — crossfade loops, never a hard restart.
- **Picture:** real luxury house footage; modern kinetic type over live plates.
- **Motion:** ultra-modern, animated, engaging, fun — not static corporate cards.
- **Transitions:** long smooth dissolves between sections (not jump cuts).
- **Camera:** steady / stabilized. Prefer locked or gentle push. No handheld shake.
- **Sponsor placement in episodes:** mid-roll (middle of the edit), not jammed after the title.
- **Show footage:** Desktop / program clips for the episode body — never use Desktop ads inside the HPM spot.
- **AI review before show:** catch issues and fix them before opening the file for the human.

## NOT OKAY

- Navy + gold “bank” title cards that look 80s / dated.
- Italic / old-broadcast typography for brand lockups.
- Typing / keyboard / clicky UI sound effects.
- Busy overdone SFX beds (whoosh spam, risers stacked, logo stings every second).
- Hard music loop seams (hear the track stop and start again).
- Shaky last clips / wobbly handheld plates.
- Full-screen static copy cards like “PRE-APPROVAL · PURCHASE · REFINANCE” on flat navy.
- Silent placeholder ads or text-only slates with no real music.
- Showing a draft to the human before QC has passed.
- Putting Desktop ad folders into the HPM creative.
